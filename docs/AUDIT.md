日期：2026-09-10。范围：项目全部 Python 模块、测试、README、配置模板、本地配置结构与权限、安装缓存；未创建、停止、删除或迁移云端资源。

## 已修复

- AFS 用户名查询失败分支引用了未定义的 `ConfigError`，现统一为可读的配置错误。
- SSH 公钥校验超时、非文本公钥、无效代理 IP/端口/认证参数不再向用户抛出原始 Python 异常；公钥相对路径以项目根目录解析。
- 代理参数不再先拼成带密钥命令再拆解：共享函数直接构造 ncat argv，显示函数单独生成不含凭据的 SSH 命令。
- 生成 ProxyCommand 时同时处理 shell 引号及路径中的 OpenSSH `%` 展开；代理凭据直接传给 ncat，不经过 shell 展开。
- 代理启动失败保留可读的缺少 ncat / 安装提示；Homebrew 使用 `brew install nmap`。
- 创建 CCI 和绑定已有 CCI 时在修改云端资源前校验代理配置。
- DNAT 复查除 ACTIVE、目标类型、目标 UID 和端口外，还检查规则 UID、创建者与删除标记，防止同名替换被误认成成功。
- DNAT 列表响应和目标服务端口增加结构检查，布尔值不再被当作端口 1；菜单拒绝不能转换为整数的 Unicode 数字。
- CCI 停止、删除、复制提交前增加所选实例身份复查；空用户 UUID 不再通过验证。
- README 修正菜单编号、依赖、重复安装描述、过时的 DNAT 状态结论及直连 SSH 提示；代理、绑定说明移到对应功能章节。

创建页两次补测：初始化只请求一次关联资源池接口；第一次选池约 1.7–2.7 秒，规格和 AFS 独立读取，AFS 随后取得 IAM 用户名。切换到另一池约 0.86–0.95 秒，只新增一次规格请求；切回先前池和重复选择同一池均为 **0 次网络请求**。表单显示具体加载状态，规格缓存按池身份隔离。

CCI/ACP 镜像搜索也已接入：先选择可访问命名空间，再按名称或标签过滤，选中后回填完整地址。实测得到 818 个带标签引用，首次读取约 26.5–28 秒；同一表单内搜索和重新打开复用内存快照，刷新才重新查询。CCR 服务列表保持按仓库展示，未把无标签仓库当作可拉取镜像。

## 查询方式

| 资源 | 实现 |
| --- | --- |
| 工作空间、AFS、VPC、EIP、命名空间 | REST 目录，按资源类型过滤；响应不完整时明确报错 |
| 关联资源池 | 专用关联接口，按数字页码读取、复用当前草稿缓存 |
| 规格 | 单池规格接口，直接读取加速卡资源键 |
| ACP 历史 | 服务端创建者、名称前缀和状态过滤；只读当前页 |
| CCI | 本人实例接口，完整性与重复分页检查 |
| DNAT | 当前创建者过滤；最多并发读取 3 个 EIP；分配端口时读取全部可见规则 |
| CCR | 首次返回整库，界面按仓库显示，每页 20 条；搜索与翻页复用快照 |
| 本地 Docker | 延迟扫描本机标签；选择后才检查镜像架构 |

CCR 与资源目录可能忽略分页参数，不能把相同的响应视作新的一页。工具检查总数、下一页和重复资源，拒绝把部分结果显示为完整列表。CCR 可访问范围不代表拥有推送权限。[官方权限说明](https://console.sensecore.cn/micro/help/docs/developer-tools/ccr/)

## 跨页面与跨进程缓存补测

2026-09-11，在同一命名空间读取 611 个镜像仓库：强制云端读取 27.6567 秒；新建列表数据源命中磁盘缓存为 0.0017 秒；另启 Python 进程读取同一缓存为 0.0016 秒。三次仓库总数一致。这些数值仅计镜像数据源读取，不含工作空间/命名空间查询和界面绘制。

镜像快照有效期 5 分钟，手动“更新云端”绕过缓存。缓存按账户、完整资源范围和命名空间身份隔离；上传成功后失效，取消上传复用。缓存不包含账户密钥，不进入 Git。

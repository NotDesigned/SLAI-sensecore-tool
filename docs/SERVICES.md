# 服务行为

[返回 README](../README.md) · [CLI 命令与参数](CLI.md)

## CCI

创建表单只编辑本地草稿。普通创建和“按照上次配置创建”均以“提交创建”为主操作，校验通过后保存计划并提交。“仅保存配置”是独立可选操作。纯文本配置表回车默认选择提交；DNAT 创建的确认页也默认选中提交。

应用与端口 Service 分开创建。两项请求分别保存 UUID request_id；提交后核对应用 UID、归属、Service 选择器和端口。请求结果未知时查询既有名称，不自动重发 POST。失败会指出已经创建的资源，保留计划供检查。

SSH 默认启用公钥认证，禁用密码认证；每个容器生成独立主机密钥。就绪探针检查本机 SSH 服务响应。自定义镜像需要兼容启动脚本，缺少 sshd 时才尝试 apt 安装。

在列表中选中运行实例后，点击“连接”才查询同订阅、同 VPC 和可用区的可访问 DNAT，匹配应用 UID 与 CCI 目标类型。多个入口优先展示容器端口 22。连接前重读实例和规则，再通过共享 SSH 检测与命令窗口呈现结果。此查询只读，不要求规则必须由本人创建。

复制先在配置表中回填源模板、资源和挂载，允许调整后以新名称提交，不迁移 DNAT。停止核对 SUSPENDED；删除核对实例消失，并清理仍属于该应用的端口 Service。无端口应用可能返回 UID 为空的虚拟 Service 视图，这种视图无需删除。身份变化时停止处理，不删除同名替代资源。

## ACP

创建 JSON 直接表达 Worker 角色、规格、镜像、命令、AFS、调度和容错。默认 NORMAL、闲时资源、单 Worker、重试次数 0。任务命令必须非空；入口模式会显式执行入口和参数。

列表通过服务端创建者筛选，并在本地复核归属，支持名称前缀、状态及分页。详情和写入前检查使用 GET；停止与删除调用 batchStop / batchDelete，但每次只传选中任务的一个名称。

复制保留可写模板，递归去掉只读字段。查询返回的每规格副本数与总副本数不能同时提交；使用总副本数时移除分配结果中的每规格副本数。新任务不会自动恢复 checkpoint，不提供当前工作空间不允许的原地重启。

## DNAT

列表汇总当前账号创建的规则，先取得 IAM 身份，再服务端筛选并本地复核；最多并发读取 3 个 EIP。任一路失败不会返回伪装成完整列表的部分结果。

新建规则先核对 EIP、网关、公网 IP 和归属，再分配随机高端口。冲突检查包含该 EIP 的全部可见规则和端口段，不仅是本人规则。检查可用不等于预留成功，提交前会再次核对。

绑定 CCI 会检查同订阅、可用区和 VPC，以及实例已有 TCP 服务端口。已有绑定迁移需确认，先解绑并核对，再绑定新目标 UID；复查 ACTIVE、目标类型、UID 和端口。绑定到 22 后显示 SSH 命令并检查入口。

删除已绑定规则先解绑；解绑不删除规则，删除 CCI 也不删除独立 DNAT。任何写入均核对所选规则 UID 和归属；未知结果不会盲目重试。

## CCR

列表范围是当前账号可访问的命名空间，不代表镜像由本人创建；API 未提供可靠的镜像创建者字段。仓库接口可能忽略分页，一次返回所有记录，因此前端分页、搜索及标签选择使用完整快照。读取失败不会当作空列表。

创建表单的镜像选择每行一项镜像与标签，自动补全完整地址；无标签仓库不参与选择。CCR 列表与创建表单共用 5 分钟本地缓存，按账户凭据指纹、区域、完整资源范围和命名空间身份隔离。重新打开表单或重启程序可复用，页面显示更新时间。“更新云端”强制刷新；刷新失败保留旧快照和错误提示。上传成功清除对应缓存，取消上传不强制重拉。

上传依赖 Docker，目标命名空间来自可访问 ACTIVE 列表；官方 Registry 按区域匹配。源镜像、目标名称和标签每次确认。资源可见性不保证可推送，最终由 Registry 权限校验。已有可用凭据不重复询问，认证失败只重新登录并重试一次。

## 本地镜像提交

两个创建表单都支持本地 Docker 标签。选择时读取镜像 ID 和 linux/amd64 架构，按原仓库名和标签生成同步目标。提交前再次核对 ID，使用不可变的镜像 ID 打标签，上传失败则不创建任务。只保存配置和取消均不上传。历史配置复用时读取当前标签，重新绑定本地镜像 ID。
